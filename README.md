# TP9 - Dashboard Final - Coderhouse

## Entrega principal

**TP9_Dashboard_Final_BianchiGisela.xlsx**

Dashboard ejecutivo desarrollado en Excel para el curso de Análisis de Datos de Coderhouse.

El proyecto integra el modelo de datos trabajado en módulos anteriores y presenta una capa final de visualización orientada al análisis de ventas.

## Instrucciones de uso y verificación

1. Descargar el archivo `TP9_Dashboard_Final_BianchiGisela.xlsx`.
2. Abrirlo con Microsoft Excel de escritorio.
3. Ingresar a la hoja `Dashboard Final`.
4. Utilizar los segmentadores de **Mes, Categoría y Región**.
5. Verificar que los KPI, gráficos y elementos narrativos se actualicen al aplicar filtros.
6. Para revisar la documentación del uso de IA, consultar `Documentacion_Uso_IA_TP9_BianchiGisela.pdf`.
7. Los archivos utilizados como fuente del modelo se encuentran en la carpeta `Fuentes`.

> Nota: si al actualizar las consultas Excel solicita la ubicación de los archivos fuente, se deben seleccionar las copias locales descargadas desde la carpeta `Fuentes` del repositorio.

## Evidencias de los requisitos

- **Diseño profesional:** hoja `Dashboard Final`, con distribución ejecutiva, paleta visual consistente, KPI destacados y cuadrícula oculta.
- **Interactividad:** tres segmentadores —Mes, Categoría y Región— conectados a los elementos del dashboard.
- **Gráfico avanzado:** gráfico de dispersión `Cantidad vendida vs. facturación por producto`.
- **Narrativa dinámica:** el título del gráfico de evolución mensual y el insight del gráfico de productos cambian según los datos filtrados.
- **Formato condicional:** el KPI de Ventas Totales cambia visualmente según el cumplimiento de la meta definida.
- **Conclusiones:** el dashboard incluye tres insights sobre Ventas, Productos y Regiones.
- **Validación con IA:** se utilizó ChatGPT para revisar las conclusiones mediante un análisis crítico tipo “abogado del diablo”.
- **Refinamiento:** a partir de esa revisión se reformularon los insights, se evitó atribuir causas no demostradas por los datos y se incorporó una nota metodológica.
- **Documentación de IA:** disponible en `Documentacion_Uso_IA_TP9_BianchiGisela.pdf` y dentro del Excel en la hoja oculta `Documentacion_IA`.

## Fuentes de datos

La carpeta `Fuentes` contiene los archivos utilizados como origen de datos para las conexiones del modelo:

- `Datos_Crudos_Transacciones.csv`
- `Tablas_Maestras_TP8.xlsx`

Estos archivos se incluyen para permitir la inspección de las conexiones y del modelo de datos.

## Contenido principal del dashboard

- Ventas Totales.
- Ticket Promedio.
- Cantidad Vendida.
- Evolución mensual de las ventas.

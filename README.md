# TP9 - Dashboard Final - Coderhouse

## Entrega principal
**TP9_Dashboard_Final_BianchiGisela.xlsx**

Dashboard ejecutivo desarrollado en Excel para el curso de Análisis de Datos de Coderhouse.

El proyecto integra el modelo de datos trabajado en módulos anteriores y presenta una capa final de visualización orientada al análisis de ventas.

## Contenido del dashboard
- Indicadores KPI.
- Evolución mensual de las ventas.
- Análisis de cantidad vendida vs. facturación por producto.
- Segmentación mediante filtros de Mes, Categoría y Región.
- Principales insights y conclusiones del análisis.
- Documentación del uso de Inteligencia Artificial incluida dentro del archivo Excel.

## Fuentes de datos
La carpeta **Fuentes** contiene los archivos utilizados como origen de datos para las conexiones del modelo:

- `Datos_Crudos_Transacciones.csv`
- `Tablas_Maestras_TP8.xlsx`

Estos archivos se incluyen como soporte para facilitar la revisión de las conexiones y del modelo de datos.
